# 💎 Jewellery E-Commerce Website

A responsive jewellery showcase website developed as a **Diploma academic project** using **HTML, CSS, Bootstrap, and JavaScript**.

The project was created to demonstrate practical knowledge of frontend web development, responsive design, website structuring, and user interface development.

## ✨ Features

* 🏠 Responsive Home page
* 💍 Jewellery product showcase
* 💎 Diamond jewellery pricing section
* 📱 Responsive design using Bootstrap
* 🧭 Navigation between website sections
* 📩 Contact and newsletter sections
* 🔗 Social media links
* 🎨 Clean and attractive user interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **Bootstrap** – Responsive design
* **JavaScript** – Interactive functionality
* **Owl Carousel** – Carousel components
* **Google Fonts** – Typography

## 🎓 Academic Project

**Project Type:** Diploma Academic Project

## 🎯 Project Objective

The objective of this project was to design and develop a modern jewellery website that provides an attractive and responsive interface for showcasing jewellery products and their pricing.

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
